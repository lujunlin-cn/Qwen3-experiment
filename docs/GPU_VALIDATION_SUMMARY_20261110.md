压显存使用 microbatch=1、梯度累积、LoRA rank=8、Decoder 非重入梯度检查点、
关闭训练 KV cache、按 64 Token 分块计算完整词表投影。DPO 顺序重算并反传

assistant Token、24 次更新，最长完整序列 287 Token，没有截断。首轮 196 个

## 效果：调参面板结果

每题型仅 4 道固定 Validation 题，用于选模型，不是独立最终验收。原题提示词，
Thinking 开启，上限 Roman 8192、Gravity/Equation 16384；平均长度只计实际
输出，包含 Thinking、错误与截断样本，不含输入。三种 RL 均独立从同一个选定
SFT 第 1 轮出发；DPO 训练 Gravity/Equation，PPO/GRPO 仅训练 Equation。

每格为 **正确率 / 截断率 / 平均输出 Token**。选定轮次分别为 SFT 1、DPO 1、
PPO 1、GRPO 2；GRPO 2 的结果已由取回的原始结果文件复核。

| 模型 | Roman | Gravity | Equation Numeric |
|---|---|---|---|
| Base | 75% / 0% / 2137.50 | 100% / 0% / 9407.25 | 25% / 25% / 12874.00 |
| SFT | 100% / 0% / 2225.50 | 100% / 0% / 7882.75 | 25% / 0% / 9485.50 |
| DPO | 75% / 0% / 1895.00 | 100% / 0% / 7750.25 | 25% / 0% / 10613.25 |
| PPO | 25% / 0% / 1807.50 | 75% / 25% / 9607.00 | 25% / 0% / 12311.75 |
| GRPO | 50% / 25% / 5010.50 | 75% / 25% / 8938.25 | 25% / 0% / 9197.00 |

- SFT 在该小面板上改善 Roman 正确率；Gravity 正确率保持 100%，平均输出
  减少约 16.2%；Equation 截断率从 25% 降至 0%，输出减少约 26.3%，正确率未升。
- DPO 相比 SFT，Gravity 输出仅略短，Equation 输出更长、正确率不变。
  三轮只形成 9 对偏好、4 次更新，训练信号稀疏。
- PPO 第三轮 rollout 获得 3/8 个正确完整回答，但调参正确率仍为 25%。按预设
  分数门槛最终选第 1 轮；该轮没有正向正确性奖励，不能声称它学会更准确解题。
- GRPO 确有两次有效更新，但当前选定模型的数学正确率仍为 25%。第 4 轮调参
  数学正确率甚至降到 0%，未选择该轮。不能因输出变短就判定任务解决。

SFT 已经改善截断和长度，因此“只有 RL 才能进一步改善这些指标”不能当作
实验前提。**本轮未实现三题全面解决，也没有证明三种 RL 均能提升数学正确率。**

## 基线与提示词路线

输出上限 512/2048/8192/16384 已全部实测。512 时三类全错且全部截断；2048
时 Gravity 和 Equation 同样全错且全部截断。8192 时 Roman 正确率 75%、无
截断；Gravity 正确率 50%、截断 50%；Equation 正确率 0%、截断 75%。
直接减小上限会损害正确率，不能当成模型学会简洁推理。

加入 Roman 1–10 映射、Gravity 反推/估计公式及 Equation 24 条公开规则后，
同一调参面板正确率分别为 100% / 50% / 0%，平均输出分别为
1757.25 / 7821.75 / 8696.00 Token，三类均无截断。提示词路线仅在 Roman 上
表现出改善，其他两题的负结果保留，未混算为训练收益。

按现有 24 条规则和官方 1% 数值容差，Train 的 586 道 Equation 中 406 道
查询答案唯一、180 道存在多个官方评分也不等价的合法输出。四道调参题中有
一道属于后者。原始标签都匹配其中一个合法输出，全部 2943 条已接受教师也
通过官方评分；没有据此改标签、事后剔除难题或放宽评分。

## 耗时与停止原因

| 方法 | 含 rollout、启动、保存、验证的总时间 | 停止原因 |
|---|---:|---|
| SFT | 28.58 分钟 | 3 轮，预设调参平台期，选第 1 轮 |
| DPO | 52.96 分钟 | 3 轮，预设调参平台期，选第 1 轮 |
| PPO | 41.88 分钟 | 3 轮，预设调参平台期，选第 1 轮 |
| GRPO | 90.00 分钟 | 第 6 轮 rollout 耗尽阶段预算，`rollout_incomplete` |

SFT 三轮纯训练约 337.50 秒，而验证约 1341.75 秒。DPO 三轮 rollout 约
1712.74 秒、包含启动等开销的训练任务约 52.48 秒、验证约 1409.90 秒。
长回答的生成和验证主导课程时间，训练反传本身更短。

GRPO 最后一轮采样峰值约 5.20 GB，终止原因是时间耗尽，不是显存超限。
预设平台期仅是小面板停止规则，不等同于充分收敛。正式 Run 从 19:34 启动到
23:37 进入最终评测约 4 小时 3 分钟；最终评测未完成，因此没有完整全流程结束时间。
